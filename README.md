# Bybit Trading Bot

Автоматический торговый бот для биржи Bybit с функциями:
- Автоматическое открытие позиций по сигналам
- Установка тейк-профита на 10%
- Автоматические докупки при снижении цены
- Мониторинг позиций через WebSocket
- Черный список для тикеров

## Установка

1. Установите зависимости:
```bash
pip install -r requirements.txt
```

2. Создайте файл `.env` в корне проекта:
```env
# Добавьте сюда свои API ключи при необходимости
```

3. Создайте необходимые директории:
```bash
mkdir -p /var/www/phyton/bot/botttss
mkdir -p /var/www/phyton/bot
```

4. Создайте файл с пользователями `/var/www/phyton/bot/botttss/users.txt`:
```
user1,YOUR_API_KEY,YOUR_API_SECRET
user2,ANOTHER_API_KEY,ANOTHER_API_SECRET
```

5. Создайте файл сигналов `/var/www/phyton/bot/signals.txt`:
```
#BTC
#ETH
#DOGE
```

## Запуск

```bash
python bot.py
```

## Настройки

В файле `bot.py` можно изменить следующие параметры:

- `MAX_POSITIONS = 5` - максимальное количество позиций
- `POSITION_SIZE_PERCENT = 5.0` - размер позиции в процентах от баланса
- `DOCOUP_SIZE_PERCENT = 5.0` - размер докупки в процентах от баланса
- `TAKE_PROFIT_PERCENT = 0.10` - тейк-профит 10%
- `FIRST_DOCOUP_DROP = 0.01` - докупка при снижении на 1%
- `BLACKLIST_DURATION = 8 * 3600` - время в черном списке (8 часов)

## Файлы

- `bot.py` - основной файл бота
- `requirements.txt` - зависимости
- `CHANGES.md` - список изменений
- `/var/www/phyton/bot/botttss/logs.txt` - логи бота
- `/var/www/phyton/bot/botttss/users.txt` - пользователи с API ключами
- `/var/www/phyton/bot/signals.txt` - файл с сигналами
- `/var/www/phyton/bot/botttss/positions_{user_id}.txt` - позиции пользователя
- `/var/www/phyton/bot/botttss/pending_docoups_{user_id}.txt` - ожидающие докупки
- `/var/www/phyton/bot/botttss/blacklist_{user_id}.txt` - черный список тикеров

## Как работает

1. Бот читает сигналы из файла `signals.txt`
2. При получении сигнала (например, `#BTC`):
   - Проверяет, есть ли тикер в черном списке
   - Проверяет количество открытых позиций
   - Открывает позицию размером 5% от баланса
   - Устанавливает тейк-профит на 10%
   - Ставит лимитный ордер на докупку при снижении на 1%
3. Мониторит цены через WebSocket
4. Подтягивает тейк-профит при росте цены
5. Обрабатывает исполненные докупки

## Безопасность

- Используйте API ключи только для торговли (не для вывода средств)
- Включите IP-whitelist в настройках Bybit
- Регулярно проверяйте логи бота
- Используйте небольшие размеры позиций для тестирования

## Поддержка

При возникновении проблем проверьте:
1. Логи в файле `/var/www/phyton/bot/botttss/logs.txt`
2. Корректность API ключей
3. Наличие достаточного баланса на счету

## Требования

- Python 3.7+
- Активный аккаунт Bybit
- API ключи с правами на торговлю
